# App Privacy Matrix — Native iOS

| Data type | Purpose | Linked | Tracking | App surface |
|---|---|---:|---:|---|
| Precise location | App functionality | Yes | No | Coordinates and collection-zone validation |
| Photos/videos | App functionality | Yes | No | Infrastructure evidence |
| Name, email, phone | Account functionality | Yes | No | Authentication and contributor profile |
| User ID | Account functionality | Yes | No | Submission ownership and progress |
| Device ID | App functionality | Yes | No | Declared in current privacy manifest; reconfirm backend use before submission |

No advertising SDK or cross-app tracking is represented in current native source. App Store Connect answers must be rechecked against production backend and bundled SDK behavior before submission.
