# App Review Notes — Native iOS

African Data Layer helps contributors map and verify real-world infrastructure. This build targets iPhone only.

Reviewer path: sign in with the review account supplied privately in App Store Connect; open Map; select a nearby priority area; start a contribution; add structured details and evidence; save offline or submit; open the queue to review status; open Profile to view verified progress.

Location is requested while using the app to attach coordinates and validate collection zones. Camera/photo access supplies infrastructure evidence. Offline drafts remain on device until the reviewer starts sync.

Credentials must be entered only in App Store Connect review fields. Never commit them here. The production team must supply an active account and a safe test geography before submission.
